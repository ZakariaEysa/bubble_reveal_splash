## 0.1.0

* Introduce `bubble_reveal_splash`, a standalone Flutter bubble curtain splash.
* Reveal any logo widget with centered growth, optional fade, slide, and custom builders.
* Customize bubble palette, count, pixel/relative sizes, shape, radius, border, gradient, and shadows.
* Support seven travel directions, seeded fields, stagger, and independent movement/scale/fade curves.
* Add automatic playback, external animation controllers, lifecycle callbacks, and reduced-motion support.
* Include a responsive branded playground, animated preview, API reference, and customization examples.
