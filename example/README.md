# Bubble Curtain Studio

Interactive example for `bubble_curtain_splash`.

```sh
flutter pub get
flutter run -d chrome
```

Explore LUMA, SOL, and NOVA palettes, seven directions, bubble counts and sizes,
timing and stagger, shadows, rounded squares, logo layering, pause, reverse,
replay, seeking, and a full-screen splash-to-content flow.

The logo starts at zero scale in the center and grows to its natural size over
the full reveal. See the package README for all customization examples.
